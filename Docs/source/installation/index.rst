Installation
============

Choose the path that matches how you intend to run Agentic FinSearch.

* :doc:`chrome_web_store` — **zero local install**: add the published extension from the Chrome Web Store and start chatting. Recommended for most users.
* :doc:`install_agent_with_installer` — run the backend in a Docker container and load the prebuilt extension. Use this if you want to host the backend yourself.
* :doc:`manual_install` — manual backend setup with ``uv`` for developers who want to modify the code.
* :doc:`start_agent_mac` — start the agent on macOS.
* :doc:`start_agent_win` — start the agent on Windows.
